# Data Types
Python is what we refer to as a **dynamically typed** language. Meaning, the data type of variables is implicitly determined by the interpreter. 

However, Python still has type-checking at runtime and it is important to note what data types are available.

We can divide data types into two groups: **primitive** and **non-primitive**.

## Primitive Data Types
Speaking literally, Python does not have true primitive data types. Although, the term is used to identify the most basic types. We can define 7 of them:

| Data Type | Description | Example |
| --------- | ------- | -------- |
| int | Whole numbers | x = 1 |
| float | Decimal values | x = 1.02 |
| bool | True or False | x = True |
| str | Sequences of characters | x = "Hi" |
| complex | Complex numbers | x = 3 + 7j |
| bytes | Sequences of single bytes | x = bytes(5) |
| NoneType | Denotes the absence of a value. | x = None |

## Non-Primitive Data Types
**Non-primitive** data types are types that are more complex and built out of several primitive types. A few examples are lists, tuples, sets, and dictionaries.
