# Variables
A **variable** is a "container" that can store a value. The general syntax for writing variables is as follows:

```
<identifier> = <value>
```

For example, to declare an integer variable with identifier `x`:
```python
x = 100
```

## Reassignment
The idiomatic term for "setting the value of a variable" is called **assignment**. Variables are what we call mutable, meaning its value can be reassigned after declaration.

```python
x = 100
x = 5 # Reassignment.
```

## Constants
Python does not have a special keyword for constants. Instead, programmers follow a standard convention of capitalizing a variable identifier for "constants".

```python
PI = 3.14159
```
